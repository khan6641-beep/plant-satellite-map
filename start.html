식물 위성 지도

먼저 프로젝트 최상단의 MAPBOX_TOKEN.js 파일에 pk.로 시작하는 Mapbox 공개 토큰을 입력하세요. 그 밖의 설정 파일은 수정할 필요가 없습니다.

식물 데이터와 검색 기능은 로컬 파일을 사용하며, 위성 지도 영상만 Mapbox에서 불러옵니다.

지도 실행

GitHub Pages 안내: 토큰 입력 후 파일을 저장소에 올리고 Pages 배포가 끝나면 HTTPS 주소로 실행하세요. Mapbox 토큰에는 해당 GitHub Pages 도메인을 Allowed URLs로 등록하세요.

세부 실행 및 데이터 교체 방법은 README.txt를 확인하세요.
