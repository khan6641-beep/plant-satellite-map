6. 현재 환경에서 직접 실행하지 못한 항목
----------------------------------------
이 제작 환경의 시스템 Chromium에는 URLBlocklist="*" 관리자 정책이 적용되어 file:// 및 로컬 HTTP URL로 직접 탐색할 수 없었습니다.
따라서 HTML·CSS·로컬 라이브러리·앱 JavaScript·실제 데이터를 동일 Chromium 엔진의 빈 문서에 그대로 주입하여 기능을 테스트했습니다.

아래 항목은 코드·파일 정적 검사는 통과했지만 이 환경에서 실제 URL 방식 런타임 검증은 하지 못했습니다.
- file:// 주소로 index.html 직접 탐색
- 로컬 HTTP 또는 정적 호스팅 URL 탐색
- 서비스 워커 설치·활성화·오프라인 재탐색 수명주기
- 실제 Esri 위성 타일 응답 및 공급자 네트워크 상태
- 실제 Android 기기 및 iPhone 기기

최종 배포 전에 사용하는 조직 네트워크와 실제 Android/iPhone에서 다음을 확인하세요.
- HTTPS 주소에서 위성 타일 표시
- 브라우저 위치 권한
- 홈 화면 추가/PWA
- 비행기 모드 전환 후 로컬 UI와 검색 유지
- 기관 방화벽에서 지도 타일 도메인 허용 여부
